Coding in frontends has been one of the most fun things I've done in this school's computer science program. It's something I want to pursue in the future and make a career out of. I've really enjoyed learning about the basic frontend stack, consisting of an index.html and style.css. That basic stack alone is already immensely powerful, and I can see how the internet begun to bloom in early times with this technology.

What piques my interest moreso is the introduction of UI frameworks like Bootstrap 5 and React, making frontend development immensely more convenient and efficient for developers. The introduction of these technologies have increased workflows throughout the industry significantly, and many of the most important websites are built using these fundamental frontend frameworks. I will be discussing Bootstrap 5 and React mainly, as these are the technologies I've been learning recently.

Bootstrap 5 is a front-end framework that makes building websites much more efficient and quick. It provides a collection of pre-designed HTML, CSS, and JavaScript components so that one doesn't have to write such styling from scratch. Things like navbars, buttons, cards, and other components are ready to use and customize on the jump. In my experience, It's made developing websites immensely faster and more seamless, as not having to fully develop essential components like buttons and navbars from scratch has made my life much more convenient. 

React is a front-end JavaScript library used to quickly build interactive user interfaces, and has now become the most widely adopted tool for front-end web development. It allows for the ability to break the UI into independent and reusable "building blocks" instead of having long blocks of code that do everything. This has made programming much more efficient and modular, allowing for code that's easier and simpler to read and understand. I can see how this would be useful in larger-scale projects with multiple developers looking at the same codebase. 

Overall, the implementation of these frameworks would make any aspiring software engineer's workflows much more efficient. As frontend is something I'm particularly interested in, it's of great importance to me to learn these essential technologies in order to become a well-rounded frontend designer.
